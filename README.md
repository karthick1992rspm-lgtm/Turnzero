# Turn Zero Club - CSV Game Library

This version keeps the static GitHub Pages site but loads the game library from `games.csv`.

## Files
- index.html
- styles.css
- script.js
- logo.jpg
- games.csv

## Game data
The library is generated from the uploaded Turn Zero collection CSV. It currently contains 136 games.

Displayed fields come directly from the CSV:
- Game name
- Player count
- Play time
- Year
- BGG rating
- Complexity / weight
- BGG rank
- Recommended player counts
- Best player count
- Recommended age

The website does not require a database.
