# Turn Zero Club Website

A free static website for Turn Zero Club.

## Files
- `index.html` - all page content
- `styles.css` - design and responsive layout
- `script.js` - game filters and mobile navigation

## Publish for free with GitHub Pages

1. Create a free GitHub account at github.com.
2. Create a new public repository, for example `turn-zero-club`.
3. Upload `index.html`, `styles.css`, and `script.js`.
4. Open the repository's **Settings → Pages**.
5. Under "Build and deployment", choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.
7. GitHub will give you a free `github.io` website address.

## Things to customise
Search `index.html` for:
- Event dates and venues
- Instagram link
- WhatsApp link
- Game list
- Community numbers

The site needs no database, hosting subscription, or build process.
